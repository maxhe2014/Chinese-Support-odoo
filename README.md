# Chinese Support Odoo / Odoo 中国支持模块

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
![Odoo Version](https://img.shields.io/badge/Odoo%20Version-17%20|%2018-%23734A96)

一个全面的Odoo本地化模块，旨在使Odoo ERP系统完全符合中国大陆的财务、税务和监管要求。

> **注意**：本项目正在积极开发中。核心功能正在陆续实现，非常欢迎社区的贡献和反馈。

## ✨ 核心特性

- **📊 符合中国会计准则**
    - 预置符合最新中国《企业会计准则》的会计科目表。
    - 自动生成标准的中文财务报表（资产负债表、利润表）。

- **🧾 金税系统集成**
    - 与官方金税盘/税务UKey服务无缝对接，管理增值税专用发票。
    - 支持自动开票、打印和红字发票处理。

- **🧮 自动化税务计算与申报**
    - 为一般纳税人和小规模纳税人准确计算增值税。
    - 生成用于增值税和企业所得税申报的预填数据。

- **🇨🇳 完整本地化**
    - 中文界面及财务单据术语翻译。
    - 支持本地化支付方式。
    - 处理中国特色的薪酬核算项目（社保、公积金）。

## 🚀 快速开始

### 环境准备
- 一个已安装的 Odoo 17 或 18 实例。
- Python 3.7+ 及 Odoo 所需依赖。

### 安装
1. 将此仓库克隆到您的Odoo插件目录：
   ```bash
   cd /path/to/your/odoo/addons
   git clone https://github.com/maxhe2014/Chinese-Support-odoo.git
   ```
2. 重启Odoo服务并更新应用列表。
3. 在Odoo应用界面中，搜索“中国”或“China”，找到并安装本模块。

### 配置
安装后，请前往 `会计 > 配置 > 设置` 进行以下配置：
- 您公司的纳税人类型（一般纳税人或小规模纳税人）。
- 金税服务的账户信息。
- 银行账户信息。
